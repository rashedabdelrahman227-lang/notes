# COMP1238 - My Course Notes

## Week 1 - Typing Practice
- Practicing touch typing helps improve typing speed and accuracy.
- Keybr and Ratatype are websites used to practice typing.

## Week 2 - Computer Memory and GitHub
- RAM is temporary memory, while storage keeps data even when the computer is turned off.
- ASCII is used to represent characters in computers.

## Week 3 - Markdown
- Markdown uses symbols to format text, headings, and lists.
- We can add links and images to Markdown files.

## Week 4 - Text Editors and Shortcuts
- VS Code is a text editor used to write and edit code.
- Keyboard shortcuts help us work faster, and regex helps us search for text patterns.

## Week 5 - Command Line
- The ls command lists files and folders in a directory.
- The cd command is used to move between directories.
